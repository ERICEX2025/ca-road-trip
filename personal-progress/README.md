# personal-progress

A living snapshot of where I'm at and where I'm headed. Not a portfolio, not a
blog — just a private home base for keeping myself honest.

## How this repo works

- **[NOW.md](NOW.md)** — where I'm at right now. A short snapshot of life, work,
  and what has my attention. Rewrite it whenever it stops being true.
- **[GOALS.md](GOALS.md)** — my immediate goals, split by horizon (this week /
  this month / this quarter). Check things off, prune ruthlessly.
- **[log/](log/)** — dated check-ins. One small file per check-in, so there's a
  paper trail of how things actually went, not just how I planned them.

## The loop

1. When something meaningful changes, update `NOW.md`.
2. When I sit down to plan, edit `GOALS.md` — add, check off, or delete.
3. Every so often (weekly-ish), drop a short entry in `log/` — what moved,
   what stalled, what I'm changing.

Commit messages are part of the journal too. "checked off first apartment
visit" beats "update".
